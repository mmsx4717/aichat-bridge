# AIChat桥接

将 QQ / 飞书群中的 **@ 机器人消息**发送到已登录的 **ChatGPT、Claude、Gemini、海外版 Qwen 网页**，再把该轮回复传回原群。

**当前版本：0.1.7 · Chrome 120+ · Manifest V3**

本地修复沿用当前版本号，不按每次修改递增；版本号调整以明确的发版安排为准。

QQ 长连接失败时立即清理旧连接的心跳与握手计时器、撤销可发送状态，忽略旧连接后续事件；若随后收到不可重试的鉴权／权限关闭码，会取消已排定的重连。Chrome 扩展错误页会保留历史 WebSocket 失败记录，恢复连接不会自动清除；请结合设置页连接状态和实际收发判断，清除历史记录后观察是否新增。

0.1.7 包含 Qwen 后台动画帧兼容：仅在桥接任务执行中、页签隐藏或无焦点、动画帧回调已等待至少 1 秒时，利用扩展唤醒补执行挂起的回调。每轮数量受限，取消的回调不会执行，页面恢复后不会重复执行，任务结束或过期即停止补执行。不会自动切页签、伪造可见状态或放宽提问归属／完成校验，其他助手保持原有行为。独立浏览器的隐藏状态测试已通过，当前 Qwen 网页的实际效果仍需群消息复测。

Qwen 后台观察覆盖输入准备、提问确认、回复读取和提交扩展，记录页签可见性、页面焦点、正文字符数、完成标记、动画帧待执行／已补执行数量，以及最终答案到达扩展的时间。不保存正文、图片、网址或凭据；每个通道仅保留最近任务的最多 16 个样本，可在「配置 Qwen → 运行状态」查看并清除。观察数据不作为发送或完成判断的依据。

0.1.6 兼容 Claude 当前网页的新回复结构：操作栏位于回复容器内部、复制按钮不再带旧标识、正文改用 transcript-engine 容器。修正由此造成的“上一条 Claude 网页提问尚未明确完成”阻塞及正文提取失败，保留生成状态、消息归属和操作栏边界校验。

0.1.5 修正 Qwen 和 Gemini 的完成检测：已经完成的回复，其操作栏仅因 `visibility:hidden` 隐藏时，不再依赖悬停或切回页签才回传。仍需本次消息归属、正文及完成标记全部通过校验；没有修改输入或发送动作。若网站自身暂停渲染，或 Chrome 冻结页面，扩展仍无法读取尚未出现在 DOM 中的答案。Gemini 间歇性发送失败、页面自行返回首页，以及 GPT 的 `cloudflare_challenge` 根因仍未确定，本次更新不代表这些问题已修复。

这是一个纯 Chrome 扩展，使用现有网页会话。日常运行不需要 Node.js、本机服务、模型 API Key 或公网回调服务器；机器人由扩展直接连接 QQ / 飞书官方接口。

## 功能

- 四种助手独立配置，可同时启用，也可只启用其中几个。
- 每个助手分别支持 QQ、飞书两个通道，可同时开启；机器人凭据、群绑定、拦截词和任务相互独立。
- 转发文字与同条消息中的图片，一次最多 4 张；支持读取本轮回复中可访问的图片并发回群。
- QQ 使用 Markdown 回复；飞书支持状态卡片，以及独立富文本正文、代码块和图片。
- 队列、任务进度、耗时和错误记录；支持取消排队任务、清除已结束记录。
- 可编辑的中英文关键词拦截，在发送到助手前检查文字。
- 浅色、深色和跟随系统外观。

例如：ChatGPT 使用 QQ 机器人 A，Claude 使用飞书机器人 B；群成员 @ 哪个机器人，消息就进入它绑定的助手对话。

## 安装

1. 从 [Releases](https://github.com/mmsx4717/aichat-bridge/releases) 下载发布包并解压，或下载本仓库源码。
2. 在 Chrome 打开 `chrome://extensions/`，开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压目录中的 **`extension` 文件夹**。
4. 点击扩展图标，打开 AIChat桥接 设置。

更新时，先等待执行中任务和回传结束，取消不再需要的排队任务。覆盖原目录后，在扩展管理页重新加载原扩展，并刷新设置页与原来绑定的 AI 标签页。沿用原目录、原扩展即可保留配置；不要先卸载扩展。刷新原标签页可以保留绑定，关闭重开后需要重新绑定。

## 配置与使用

### 1. 准备机器人

需要你自己的官方机器人 App ID / App Secret，在扩展设置中填写。仓库和发布包不提供可共用的机器人凭据。

**QQ 官方机器人**

在 [QQ 开放平台](https://q.qq.com/) 创建机器人，按平台当前要求开通群聊能力、配置可使用的群和成员，并将机器人加入目标群。

- AppID 使用平台提供的数字 ID。
- 只处理群内 @ 机器人的消息，不处理私聊、频道或未 @ 的普通群消息。
- 群绑定使用 `group_openid`，不是可见的 QQ 群号。
- 支持官方消息中可解析的引用文字和可下载图片；引用与本次附图合计最多 4 张。

**飞书应用机器人**

在 [飞书开放平台](https://open.feishu.cn/) 创建应用并启用机器人能力：

- 订阅 `im.message.receive_v1`，事件接收方式选择「使用长连接接收事件」。仅配置卡片回调不能收到群消息。
- 配置接收群内 @ 消息权限 `im:message.group_at_msg:readonly`、发送权限 `im:message:send_as_bot`。
- 图片上传需要 `im:resource:upload` 或 `im:resource`；下载群图片需要 `im:message:readonly`、`im:message.history:readonly` 或 `im:message` 之一。权限名称及可申请范围以平台后台为准。
- 发布应用版本，并将机器人加入目标群。群绑定使用 `chat_id`。

### 2. 选择助手与通道

在设置页选择「配置 ChatGPT / Claude / Gemini / Qwen」，再选择「配置 QQ / 飞书」，保存对应机器人的凭据，打开需要的通道和助手开关。

「配置」按钮只切换编辑对象，开关才控制是否运行。每个助手都可以同时连接 QQ 和飞书，最多八个通道同时运行。**不同助手不能复用同一平台的机器人 App ID**；同一助手的 QQ、飞书也需分别绑定独立的专用对话与标签页。

### 3. 绑定专用网页

1. 在 Chrome 登录要使用的助手，新建一个专用对话，手动发送一句话，等待生成正式会话地址。
2. 在目标群 @ 对应机器人一次，让扩展发现该群。
3. 在设置 →「群与网页」点击「刷新状态」，选中该群和已打开的专用对话，点击「绑定此对话」。
4. 在群里发送 `@机器人 只回复：连接成功`，检查网页与群内回复。

| 助手 | 支持的会话地址 |
| --- | --- |
| ChatGPT | `https://chatgpt.com/…/c/…` |
| Claude | `https://claude.ai/chat/…` |
| Gemini | `https://gemini.google.com/app/…` 或 `https://gemini.google.com/u/<数字>/app/…` |
| Qwen 海外版 | `https://chat.qwen.ai/c/…` |

首页、分享页、国内版 Qwen 和其他网站不能绑定。一个群使用一个专用对话和标签页，群成员会共享该对话上下文。任务运行期间请勿手动编辑输入框、发送其他消息或切换会话，避免消息归属不清导致任务停止。

### 4. 图片与回复样式

将 @、问题与图片放在**同一条消息**中；飞书使用同条图文消息。分开发送的图片不会自动拼入相邻提问。扩展会确认附件后再提交图文，图片检查失败时整条任务停止，不会悄悄丢图后只发送文字。

| 限制 | QQ | 飞书 |
| --- | --- | --- |
| 输入图片 | 最多 4 张；单张 10 MB、合计 30 MB | 同左 |
| 输出图片 | 最多 4 张；单张 4.9 MB，并受回复条数限制 | 最多 4 张；单张 10 MB、合计 30 MB |
| 文字回复 | Markdown | 富文本，或与状态同卡片展示 |
| 进度提示 | 设置页与助手网页 | 设置页、助手网页及群内状态卡片 |

图片支持范围取决于网页实际提供的可读取内容。未知外链、画布、嵌入式 Artifacts、未加载图片或无法下载的文件不保证回传；扩展不会为助手增加网站本身没有的图片生成能力。代码也必须完整出现在页面中，折叠或虚拟化导致内容不完整时会停止转发并提示。

## 运行边界与排错

- **保持 Chrome 与绑定标签页开启。** 退出浏览器、电脑休眠、页面冻结、网络中断或登录过期会影响处理。关闭设置页不影响运行。
- **后台执行不会自动切换标签页。** 四个助手可并行；任务期间扩展每秒通知网页复查已有任务，并临时关闭该标签的自动丢弃，结束后恢复原设置。这有助于处理后台计时器延迟和已完成但未回传的回复，不能强制解除浏览器冻结或让网站继续渲染。若仍经常暂停，可在 Chrome 性能设置中把对应 AI 网站加入「始终保持活跃的网站」；保持 Chrome 窗口开启，电脑不要休眠。
- **网页变化可能导致适配失效。** 扩展依赖网页输入框、消息结构和完成标记，不是模型服务的官方 API；模型可用性、额度和地区限制仍由网站决定。
- **Cloudflare / 登录验证需要本人处理。** ChatGPT 对符合条件的任务有有限次数的刷新和原回复重试；长时间闲置后可在新任务提交前按条件刷新一次。这不能保证恢复，不会代答验证码、绕过安全验证或无限重试。
- **Qwen 正文可能晚于消息框出现。** 若已识别到本次唯一的新消息、但正文仍为空或仅显示开头，扩展会在原任务时限内继续等待；只有提问文字完整匹配后才接收答案，不会重新点击发送。同一个仍在页面中的消息行可将临时标识更新为服务器标识一次，仍须通过完整正文和消息归属校验。消息行与标识一起被替换、正文不同或出现其他新消息时会停止任务；始终未出现消息则按原确认窗口超时。
- **平台有时限。** QQ 被动回复须在原消息后 5 分钟内完成，每条原消息最多回复 5 条，文字分段与图片共用额度；扩展预留发送时间，网页生成最长等待 4 分钟。飞书排队最长 15 分钟、网页生成最长 10 分钟。实际额度以平台规则为准。
- **“新增网页消息与本次群消息不同”是消息归属校验。** 扩展只接收与本次群提问完整匹配的网页消息；初始正文只挂载一部分时会在原确认时限内等待，不会因为前缀相同就转发答案。实际文字不同、人工编辑或出现其他新消息时仍停止。
- **失败任务不会自动重新输入提问。** 先查看设置 →「运行记录」和网页角标；处理网页错误、遗留草稿或附件后，可从群中重新发起。排队任务可以手动取消。已经报错结束的任务，即使之后手动重试成功，也不会自动接管该结果并回群。
- **关键词拦截有边界。** 它是本地文字匹配，支持中英文常见大小写、全半角和分隔变体；不做语义审核，也不分析图片内容，可能漏判或误判。

报告问题时，请附扩展版本、助手与通道、任务阶段、已脱敏的错误文字及复现步骤。不要提交真实凭据、Cookie、登录令牌、完整配置导出或包含群聊隐私的页面快照。

## 凭据与数据

机器人凭据保存在当前 Chrome 配置文件的扩展本地存储中，用于向对应的 QQ / 飞书官方服务认证，不传入助手网页。扩展不调用 Cookie API，也不要求导出网页登录凭据。

本地扩展存储**不是加密密钥保险箱**。能够访问你的浏览器配置或本机账户的人可能读取其中的数据。请只在受信任设备使用；不要把浏览器配置、迁移文件、配置导出、缓存或真实凭据提交到 GitHub。若密钥泄露，应在机器人平台撤销并重新生成。

群消息和图片会发送给所绑定的 AI 网站，最终回复会发回原群；请确保群成员知晓这一点。任务记录和图片缓存保存在本地用于排队、恢复和回传。「清除已结束记录」主要清理列表展示，不代表清除全部缓存或去重数据。

## 开发与检查

日常安装无需构建。开发检查需要 Node.js 22 或更新版本：

```sh
npm ci
npm test
npm run check
```

Node 测试覆盖网页适配、队列、消息与图片归属、机器人配置隔离、富文本处理和失败恢复；使用模拟 Chrome / 平台接口，不发送真实群消息。隔离 Chromium 回归说明见 [test/browser/README.md](test/browser/README.md)，用于补充 JSDOM 与真实浏览器的行为差异。

测试使用脱敏页面样本，不等于当前线上网站的端到端保证。改动网页适配器后，应在专用测试群与对话中验证文字、图片和连续任务。请勿把真实会话、带签名的图片链接或个人路径写入测试样本。
